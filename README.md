# Laravel_ToDo
LaravelでToDoリストの制作


### 使用言語：
・PHP（主にLaravelを使用）
・JavaScript（新規登録ページのフォーム未入力時のアラート表示に使用）
・HTML / CSS（ページのデザインに使用）


### 変更を加えた点
 ・CSSを使用してページデザインを制作
 ・JavaScriptを使用してアラート表示を追加した
 ・利便性を考え遷移ページボタンやaタグを追加した
